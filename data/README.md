# Dataset Documentation

## Overview
This folder contains the dataset used in the Supply Chain Analytics project. The data is used to analyze sales performance, profitability, shipping and delivery performance, product trends, and customer and geographic patterns.

## Dataset Files

| File | Description |

## How to Obtain the Dataset
1. Obtain the dataset from its original source.
2. Review the dataset licence and usage conditions.
3. Place the required CSV file(s) in this folder.
4. Check that the filenames match the paths used in the notebooks.
5. Run the notebooks in the order described in the main project README.

## Data Preparation
The dataset will be examined and prepared for analysis. This may include:
- Checking missing and duplicate values.
- Validating data types and inconsistent values.
- Creating useful date and delivery-performance features.
- Validating sales, profit, discount, and order-level calculations.
- Preparing data for exploratory analysis and Power BI reporting.

## Privacy and Usage
Do not upload data containing personal, confidential, or sensitive information unless you have confirmed that sharing it is permitted. If the dataset cannot be redistributed, download it separately from the original source and keep the raw file out of the public repository.
